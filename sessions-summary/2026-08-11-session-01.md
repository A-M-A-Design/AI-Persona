# Session 01 — 2026-08-11 : du plan au POC complet

Résumé de la session de travail avec Claude Code (Fable 5). Objectif de la
session : cadrer puis construire le POC du portfolio conversationnel AI Persona.

## Ce qui a été décidé (cadrage)

- **Produit** : remplacer le portfolio Notion/PDF par un chat avec la version
  IA d'Arthur (réf. poulos.co), URL publique à terme pour les recruteurs.
- **Stack** : Next.js (App Router, TS) + Vercel AI SDK → API Claude ; POC
  local d'abord, Vercel ensuite.
- **Modèle** : `claude-haiku-4-5` (maîtrise des coûts), configurable via
  `CHAT_MODEL` — jamais codé en dur.
- **Theming** : un persona = une « marque » au sens Accor. 3 thèmes complets
  générés sur le contrat ~870 variables `--wel-*`, switch par attribut
  `data-persona`, dark par `data-color-mode` (6 combinaisons).
- **IP Accor** : les CSS/tokens WDS bruts ne sont **jamais commités**
  (`styles/welds-src/` gitignoré, extrait localement par `npm run
  welds:install` depuis le zip). Les thèmes générés (valeurs personnelles)
  sont committables. Le passage en repo public ne nécessitera aucune
  réécriture d'historique.
- **Règle tokens** : le CSS applicatif ne consomme que `--wel-sem-*` /
  `--wel-comp-*` — jamais `--wel-prim-*` ni les alias bsem/bcomp.
- **Règle d'or git** : branche dédiée + PR + entrée CHANGELOG pour tout
  changement (imposé par le template de PR).

## Incidents gérés

- **Clé API invalide** : la clé fournie est refusée (`401 invalid x-api-key`).
  Une clé Anthropic valide (`sk-ant-api03-…`, ~100 caractères) est nécessaire
  pour valider le streaming réel et les golden questions.
- **docx embarqué par erreur** : `article/…v2.docx` a été retiré du commit
  (amend + force-push immédiat, historique GitHub propre) ; `.gitignore`
  couvre désormais `*.docx` et `article/`.
- **MCP GitHub** : le serveur distant OAuth échoue (pas d'enregistrement
  dynamique de client) ; on utilise le MCP GitHub de la config utilisateur
  (npx + token) et l'API REST GitHub pour créer les PRs.
- **AI SDK v7** (plus récent que prévu) : `system` → `instructions[]` (qui
  porte le `cacheControl`), `convertToModelMessages` asynchrone.
